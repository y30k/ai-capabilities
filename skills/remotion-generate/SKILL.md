# Remotion Generate

Read `references/workflow.md` before editing compositions or running render commands. Reuse the installed Remotion version, registered composition IDs, asset conventions, and project scripts. Never place credentials, signed URLs, customer data, or private production props in command arguments, tool logs, fixtures, renders, or durable reports; use project-approved secret injection and redacted/synthetic inputs. Ask before adding dependencies, using paid or production services, overwriting output, starting a materially expensive full render, or staging a submission candidate unless staging was already requested.

## Documentation Output

Write durable creative briefs and render reports under `docs/remotion-generate/` or a user-specified path under `docs/`. Never store generated documentation in agent-state directories such as `.agents/`, `.pi/`, `.codex/`, or `.claude/`.
